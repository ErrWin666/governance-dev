# ERR-027 — Malformed hook command → global 127 fail-closed (all tools dead)

**Type**: self-inflicted lockout (config corruption by repair script)
**Path**: `%APPDATA%\devin\config.json` hook commands × `fix_l4_j.py` substitution
**Discovered**: 2026-11-11 — fresh R3 session, every tool blocked exit 127
**Status**: 🔴 OPEN — owner must fix config (P4 blocks agent write to Devin config)

## Description

`fix_l4_j.py` replaced `wsl.exe -d Ubuntu-24.04 -e bash` with
`/c/Program Files/Git/bin/bash.exe` but **left the leading
`/c/Windows/System32/` prefix**, producing:

```
/c/Windows/System32//c/Program Files/Git/bin/bash.exe -c "..."
```

Git Bash reads the first token up to the space =
`/c/Windows/System32//c/Program` → `No such file or directory` →
**exit 127** → `fail_closed` denies EVERY tool call in any new
session. Reproduced verbatim: `RC=127`.

## Why the editing session saw success

Hooks are **loaded once at SessionStart** (session-cached). The
editing session kept its old WSL hook config — gate.log shows
`cwd=/mnt/c/` through 15:51 AFTER the config was corrupted. The
malformed command only detonated in the NEXT session.

## Root cause chain

1. Substring replacement without whole-field atomicity (same class as
   ERR-019 partial-write lockout — THIRD recurrence).
2. No post-write validation: the hook command was never spawned
   end-to-end from a *fresh* context before declaring success.
3. `fail_closed: true` correctly converted hook failure into total
   denial — gate did its job; the transport was the bug.

## Fix

Replace (×3) `/c/Windows/System32//c/Program Files/Git/bin/bash.exe`
with `/c/PROGRA~1/Git/bin/bash.exe` — 8.3 short name verified locally
(`RC=0`, no spaces → no JSON quoting needed). Verified alternatives:
quoted `"/c/Program Files/Git/bin/bash.exe"` also `RC=0`.

## Rules learned

- **Hook config changes are only proven by a NEW session** — the
  editing session always runs stale hooks. Any future hook edit must
  include a fresh-session smoke test before declaring success.
- Prefer space-free executable paths (8.3 names) in hook commands —
  survives both shell-parsed and naive-split spawn models.
- External confirmation: Devin/other-agent hooks on Windows run
  through Git Bash; broken paths → exit 127 (docs.devin.ai hooks,
  claude-code#54640, stablyai/orca#27713).
