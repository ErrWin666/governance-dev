# ERR-008 — permissions.deny is dead code

**Type**: Harness defect / dead feature
**Discovered**: 2026-11-08, session #14
**Status**: Documented — do not rely on it

## Description

Devin's `permissions.deny` rules in `config.json` do not block tool execution.
Even plain `rm probe.txt` executes despite an `Exec(rm)` deny rule. 4 payloads
tested: plain `rm`, `;`-chained, `bash -c`, `$var` expansion — all executed.

## Root cause

Prefix-match implementation does not apply to the exec tool surface; config
denies are inert.

## Fix / Mitigation

Do NOT rely on `permissions.deny`. Use `gate.sh` + OPA (P1–P5) for enforcement.
Documented in STATE.md §2.

## Lesson

Never trust a deny mechanism without testing the un-evaded base case.

## New rule

**Rule 27** — any "deny" feature must be proven with a base-case test before
being relied upon.
