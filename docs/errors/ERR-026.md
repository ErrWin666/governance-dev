# ERR-026 — Windows backslash paths bypass P13 (bashlex strips `\`)

**Type**: bypass (live-verified by cold verifier session)
**Path**: `policies/exec_analyze.py` (analyze) × `p13` seg_match
**Discovered**: 2026-11-11 — fresh verifier session, probe 3
**Status**: ✅ FIXED 2026-11-11 — union-parse; live re-denied

## Description

`echo probe >> "C:\governance-dev\policies\probe.txt"` was ALLOWED.
bashlex strips `\` inside double-quoted strings, so the write target
became `C:governance-devpoliciesprobe.txt` — a single slashless word.
`seg_match` needs a `/`-boundary → miss; `ok==true` suppressed the
string fallback → deny never fired.

## Fix

`analyze()` now parses **both** the raw text and a backslash→slash
normalized copy, unioning ASTs (`exec_analyze.py`). Same write with
`C:/` or relative paths was already denied; `C:\` now matches — live
re-test: `P13-EXEC-WRITE` denied `probe2.txt`.
