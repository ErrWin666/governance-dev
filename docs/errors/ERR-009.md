# ERR-009 — devin -p --config is a dormant bypass

**Type**: Harness bypass vector
**Discovered**: 2026-11-08, session #14
**Status**: Mitigated (no auth login)

## Description

`devin -p --config <clean.json>` can spawn a subprocess with overridden config,
bypassing ALL governance (hooks, policies). Currently blocked ONLY by the CLI
being unauthenticated (`devin auth login` would arm it permanently).

## Root cause

CLI auth wall is the only barrier; no OS-level or config-level protection.

## Fix / Mitigation

- Do NOT run `devin auth login`.
- Documented in STATE.md §2.
- If auth is ever needed, wrap the `devin` binary in an ACL and monitor auth
  state.

## Lesson

Dormant bypasses are more dangerous than active ones because they are invisible
until triggered.

## New rule

**Rule 28** — any CLI subcommand that accepts a `--config` override must be
treated as a potential bypass; test it before trusting the harness.
