# ERR-004 — Mid-session hook is silently inactive

**Type**: Lifecycle constraint / silent-failure mode
**Discovered**: 2026-11-09 — B1.0 partial test, current session
**Status**: Documented — interim procedure applied

## Description

A hook added mid-session is silently inactive. No error, no warning — only missing rows in the log. The agent cannot distinguish "hook ran and logged nothing" from "hook never fired."

## Root cause

Devin hooks are loaded at session startup (`SessionStart`). Config changes to `hooks` require a restart — the running session never re-reads `config.json`.

## Interim fix

Treat B1.0 as INCONCLUSIVE until a fresh session proves coverage. No coverage claim made this session.

## Final fix

B1.0 procedure must always start with a fresh session after any hook config change. `/hooks` verification is a mandatory first step before coverage tests.

## Regression rule

Any coverage claim without a matching fresh-session log row is invalid by construction.
